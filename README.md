# Plumber Ring

A 3D browser boss-rush: a short plumber vs. four Elden Ring–style bosses in a sunny meadow.

**Play:** https://dmeacham12.github.io/plumber_ring/

## Controls

| Key | Action |
| --- | --- |
| WASD | Move |
| Space | Jump |
| Left click | Spin attack (also destroys daggers and orbs) |
| Jump + Right click | Ground pound |
| Shift | Toggle sprint |
| Ctrl | Dodge toward the direction key you're holding |
| Mouse | Camera |
| Q / Middle click | Lock on |
| R | Heal (Mushroom Flask) |
| F | Fullscreen (also stops Ctrl+W from closing the tab) |
| M | Mute |
| Esc | Pause |

## Bosses

1. **Margrit, the Fell Omen**
2. **The Golden Sentry**
3. **Maleka, Blade of the Scarlet Bloom**
4. **Radahan, Starscourge**

Built with [three.js](https://threejs.org/) in a single HTML file.
